title: Bring the whole folder
---

- Drop a whole folder of clips on the upload page, or pick one with the new Choose folder button. Clips are grouped by the folder they came from, and the site takes a guess at each one: the game from the folder name, the date from the file name (or from the video itself), and who's in it from any names it spots. Guesses are marked so you can fix them before you hit Upload, and anything that isn't a video gets skipped.
- Games are real games now. Start typing one and pick it from the list, cover art and all. Covers show up on clips and in the game filter, so there's no more "Valorant" and "valorant" living side by side.
- Fix lots of clips at once. Hit Select on the clips page, tick the ones you want (or select everything showing), and set the game, add or remove tags, or add or remove people across all of them. Nothing anyone else added disappears unless you remove it.
- Get tagged in a big batch and you'll see one "tagged you in 40 clips" instead of 40 separate pings. Tags on a clip that's still processing wait until it's ready to watch.
